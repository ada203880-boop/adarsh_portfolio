# Adarsh Panda — Immersive Developer Portfolio

A responsive dark-neon portfolio built with React, TypeScript, Vite, Lucide icons, and custom CSS. The layout is inspired by the supplied portfolio reference: dark navy background, violet/cyan atmospheric lighting, character artwork in the hero, floating technology labels, service cards, a career timeline, project showcases, technology stack, certifications, and contact details.

## Requirements

- Node.js 20.19+ (Node 22 recommended)
- npm

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

## Deployment

Deploy the project folder to a Vite-compatible host such as Vercel or Netlify. Configure the build command as `npm run build` and output directory as `dist`.
